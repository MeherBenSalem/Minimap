# Odyssey Map (1.21.1)

Client-side minimap mod for Minecraft 1.21.1 with Fabric and NeoForge loaders.

## Requirements

- JDK 21
- Minecraft 1.21.1

## Build

```bash
./gradlew :fabric:build :neoforge:build
```

## Run (dev)

```bash
./gradlew :fabric:runClient
./gradlew :neoforge:runClient
```

Open this folder (`1.21.1/`) as the Gradle project in IntelliJ with JDK 21.
